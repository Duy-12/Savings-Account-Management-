## 🛠 Công cụ đề xuất
- **Draw.io / diagrams.net**: Miễn phí, dễ xuất file PNG / SVG và lưu file nguồn `.drawio`.
- **StarUML / Visual Paradigm**: Thiết kế chuẩn UML 2.0.
- **PlantUML / Mermaid**: Vẽ sơ đồ dạng code markdown.
